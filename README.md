# КАСПУР 3000 БАЗИС

Демо продукта CASPOL: https://andrewmironov13.github.io/kaspur-3000/

Vite + TypeScript. Шрифты и изображения хранятся локально, внешних UI-библиотек нет.

## Запуск

```sh
npm install
npm run dev
```

В рабочем окружении Андрея `node_modules` — ссылка на общий каталог. Не заменять её без необходимости.

## Проверка сборки для GitHub Pages

```sh
VITE_BASE=/kaspur-3000/ VITE_NOINDEX=1 VITE_DEMO=1 npm run build
VITE_BASE=/kaspur-3000/ npm run preview
```

Открывать `/kaspur-3000/` на порту 5291. Публикация: `sh scripts/deploy-demo.sh`. Скрипт проверяет TypeScript, собирает демо с noindex и обновляет gh-pages обычным push, сохраняя историю.

## Статус

- Это демонстрационная версия с noindex
- Форма отправляет заявки через FormSubmit на `info@caspol.ru`. Для другого адреса можно передать `VITE_FORM_ENDPOINT` при сборке. Если FormSubmit запросит активацию, получателю нужно подтвердить адрес по письму
- Пять вариантов гаммы доступны перед подвалом; сиреневая используется по умолчанию
- Упаковка показана в 3D, цех, лаборатория и консистенция показаны на иллюстрациях
- Прежде чем печатать этикетки, нужна маркировка из паспорта безопасности и утверждение производителя
- До рабочего запуска нужны настоящие фотографии производства, проверка доставки писем, домен и аналитика
